# Audio Asset Instructions

This directory contains the background music for the portfolio:
- File name: `solar-sailer.mp3`
- Track: **"Solar Sailer"** from the *TRON: Legacy* Original Motion Picture Soundtrack (by Daft Punk).

To use your own licensed or high-quality audio file:
1. Replace `solar-sailer.mp3` in this folder (`src/assets/audio/solar-sailer.mp3`) with your own copy.
2. (Optional) Also copy it to `public/audio/solar-sailer.mp3` for direct static serving.
3. The portfolio will automatically load and seamlessly play your track with smooth cinematic fading.
